## Backend

This is the backend of the application. It is responsible for the business logic and the data storage.

### UV Project

This is the UV project for the backend. It is responsible for the project management and the dependencies. To activate it run:

```bash
source .venv/bin/activate
```

The dependencies are managed by the `pyproject.toml` file. To install them for the first time run:

```bash
uv sync
```
